# Inspiration: designers, galleries, best-designed shops

Use these to learn **principles**: hierarchy, rhythm, restraint, motion quality,
storytelling. Never copy a site's look, brand, assets or layout one-to-one. The site
you build should look like it belongs to its own business. Sites change; if you can
browse, check the current version before citing a detail.

## 1. Designers and writers to learn from

| Who | Learn |
|---|---|
| Dieter Rams, "10 principles of good design" | restraint, honesty, "as little design as possible" |
| Massimo Vignelli, *The Vignelli Canon* | grids, a few typefaces used well, discipline |
| Adam Wathan & Steve Schoger, *Refactoring UI* | practical hierarchy, spacing, colour, depth; fixing "developer design" |
| Jon Yablonski, *Laws of UX* | Hick, Fitts, Jakob, proximity: why layouts work |
| Nielsen Norman Group (Jakob Nielsen, Don Norman) | usability heuristics, research-backed patterns |
| Baymard Institute | e-commerce UX research: product pages, checkout, filters, mobile |
| Matthew Butterick, *Practical Typography* | body text, line length, spacing, typographic details |
| Ellen Lupton, *Thinking with Type* | type hierarchy and composition |
| Emil Kowalski (animations.dev; Sonner, Vaul) | UI animation craft: timing, easing, when not to animate |
| Josh W. Comeau | CSS mastery, spring physics, playful but polished interaction |
| Rauno Freiberg | interface details and interaction polish |
| Jhey Tompkins | creative CSS, scroll-driven animations |
| Vitaly Friedman (Smashing Magazine) | patterns for forms, tables, navigation, e-commerce UX |
| Sarah Drasner | SVG animation and motion design on the web |

## 2. Studios known for web craft and motion

- **Locomotive** (Montréal) — smooth scroll storytelling, editorial layouts.
- **Active Theory**, **Resn** — WebGL and immersive experiences (use sparingly).

## 3. Galleries for research

- **Awwwards** (filter by category e-commerce, by "Site of the Day") — high craft,
  sometimes over-designed; judge usability yourself.
- **Godly** — curated modern web design, strong motion examples.
- **SiteInspire** — clean, typographic, less trendy.
- **Land-book**, **Lapa Ninja** — landing pages by category.
- **Mobbin**, **Page Flows** — real product flows (sign-up, checkout, onboarding).
- **Refero** — UI patterns from real products, searchable by element.
- **Minimal Gallery**, **Httpster** — minimal and experimental.
- **Shopify Editions/brand showcase**, Shopify theme store top themes — what current
  commerce UX looks like at scale.
- Caution with **Dribbble/Behance**: many shots are concepts never shipped; good for
  mood, bad as proof of usability.

## 6. Polish market conventions worth knowing

Study for patterns Polish customers already expect (not for visual style):
- **Allegro** — trust signals (ratings, "Smart!", delivery dates), product Q&A,
  seller info, delivery options presentation.
- **Zalando, Answear, LPP brands (Reserved, Mohito, Sinsay)** — fashion catalogue UX in
  Polish, size charts, returns communication, filters.
- **InPost** — Paczkomat selection map widget expectations; "dostawa jutro" promise.
- **Booksy** — booking flow expectations for beauty and barbers.
- **Pyszne.pl, Glovo, Wolt** — food ordering expectations (menu structure, modifiers).
- **mBank / BLIK flows** — customers expect BLIK first, fast, mobile-friendly payment.
- **Google Maps reviews** — for local businesses, the review count and rating there is
  the main trust signal; show it if real.

## 7. How to use a reference

1. Name what you take: "rytm sekcji jak u Aesop: duże zdjęcie → krótki tekst → spokój",
   "storytelling przewijania jak Apple, ale z 3 krokami zamiast 30".
2. Translate it into this business's concept, palette and content.
3. Check it still works on mobile and loads fast.
4. Tell the user which principles came from which reference, in one short line each.
